# Smile Scheduler Pro

Construye la aplicación web OdontoSystem v4.3 basada en el documento PDF adjunto con animaciones y transiciones fluidas. Debe incluir: 1) Módulo Paciente (onboarding/login, catálogo de dentistas con filtros en Ica y colegiatura COP, agendamiento con temporizador regresivo de reserva y flujo de pago Yape/Plin con comprobante, dashboard con historial clínico y medidor de strikes de puntualidad); 2) Módulo Odontólogo (agenda interactiva por horas, KPIs de ingresos en Soles S/, registro de notas médicas y control de ausencias); 3) Widget de Chatbot conversacional con carrusel de dentistas y opciones clicables; 4) Todas las reglas de negocio visuales (expiración de cupo, suspensión por strikes, comprobante en revisión).
